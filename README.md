# Humberto Hernandez Portfolio

Field engineering, systems integration, and technical operations.

## Website

https://wificowboy.github.io/Portfolio/

## Implementation

Buildless HTML and responsive CSS with an inline SVG illustration. No frameworks, packages, API keys, or build step. Native browser navigation and disclosure controls keep the content accessible without JavaScript. Site assets are served locally using relative paths. Resume links lead to the LinkedIn profile's Featured section. A GitHub-hosted PDF is not included.

## Project evidence

WHITE RABBIT and FORGE Core are personal Python demonstrations using synthetic records, developed with AI assistance. They are separate from AT&T work. Source and case studies: https://github.com/WiFiCowboy/white-rabbit

## Local review

Serve the repository with any static HTTP server, then open index.html through that server. Review desktop and mobile layouts, section navigation, project links, and the resume download.
